# 냥냥식당 (Nyanyang Restaurant) 게임 기획서

## 1. 개요 (Overview)
- **게임명:** 냥냥식당 (Nyanyang Restaurant)
- **장르:** 요리 / 경영 시뮬레이션 / 미니게임
- **타겟 유저:** 7~11세 어린이
- **플랫폼:** 모바일 웹 환경 (스마트폰 브라우저 최적화, 터치 친화적 UI, 세로 모드 전용)
- **핵심 컨셉:** 마트에서 재료를 사서, 주방에서 조리 도구를 써서 요리하고, 동물 손님과 가족들에게 대접하여 돈과 하트를 버는 캐주얼 게임.

## 2. 세계관 및 캐릭터
- **주인공 (플레이어):** 요리를 좋아하는 꼬마 고양이 셰프
- **가족:** 엄마 고양이, 아빠 고양이, 동생 고양이 (자유롭게 만든 요리를 대접할 수 있음)
- **마트 아저씨:** 푸근하고 친절한 곰
- **일반 동물 손님:** 강아지, 토끼, 여우, 판다, 수달, 햄스터 등 귀여운 동물 친구들
- **스페셜 손님:** 가끔 찾아오는 특별한 손님으로, 스페셜 주문을 성공하면 훨씬 더 큰 보상을 줍니다.

## 3. 핵심 플레이 흐름 (Core Loop)
1. **주문 받기:** 식당 홀에 다양한 동물 손님이 찾아와 말풍선으로 요리를 주문합니다. 
   - 시크릿 힌트: 가끔 손님이 "계란에 소금을 뿌려볼까?" 처럼 시크릿 레시피 힌트를 대화창으로 흘립니다.
   - 단일 주문 & 무제한 대기: 주문은 한 번에 1개씩만 들어오며, 손님은 시간 제한 없이 끝까지 기다려줍니다.
2. **마트에서 장보기:** 부족한 재료를 마트에서 돈을 주고 구입합니다. (레벨에 따라 우유, 밀가루 등 고급 재료 해금)
3. **요리하기 (상세 조리 과정):** 
   - **조리 도구 선택:** 단순히 재료만 넣는 것이 아니라, 프라이팬, 냄비, 반죽용 보울(Bowl) 등 요리에 맞는 도구를 먼저 선택합니다.
   - **조리 액션:** 가스레인지 불 켜기, 반죽기에 물과 밀가루를 넣고 섞기 등 실제 요리 과정이 단계별로 진행됩니다. (예: 팬케이크 = 보울에 밀가루+물 넣고 섞기 ➡️ 프라이팬으로 옮기기 ➡️ 불 켜기 ➡️ 굽기)
   - **미니 액션 추가:** 화면 터치 연타, 스와이프로 젓기 등 손맛이 느껴지는 인터랙션 추가.
4. **서빙 및 보상:** 손님에게 요리를 주면 만족도에 따라 돈과 ❤️하트를 받습니다.
   - **피버 타임 (Fever Time):** 연속 성공 시 조명이 켜지고 배경음악이 빨라지며 보상(머니/하트)이 2배가 됩니다.
5. **화려한 도감 연출:** 새로운 요리나 시크릿 레시피를 처음 성공하면 화면 가득 폭죽이 터지고 [NEW] 황금 마크가 찍혀 수집욕을 자극합니다.
6. **꾸미기 상점:** 모은 하트로 냥냥 셰프의 모자나 식당 인테리어를 구매합니다.

## 4. 재료 및 레시피 시스템
- **기본 재료 (무료/무제한):** 설탕, 후추, 소금, 식용유, 참기름, 고추가루, 물 (양념선반에 항상 구비)
- **구매 재료 (마트):** 라면, 계란, 밀가루, 우유 등 (레벨이 오르면 해금됨)
- **레시피북:** 요리 중 팝업으로 언제든 확인 가능. 레벨업 시 자동으로 새 레시피 추가.
- **시크릿 레시피:** 레벨과 상관없이 우연한 툴/재료 조합으로 발견하면 오픈됨. (레벨당 1~2개 존재)

## 5. 보상 시스템 (경제)
- **기본 수익 보장:** 어떤 요리를 만들든 항상 재료비 이상의 머니(코인)를 보상으로 받습니다.
- **가족 서빙:** 주문받지 않은(실패했거나 연습용) 요리는 가족에게 주어 기본 돈과 소량의 경험치를 얻습니다.
- **만족도 보너스:** 손님이나 가족이 요리를 먹고 만족도가 높을수록 더 많은 '보너스 머니'를 받습니다.
- **하트(특별 재화):** 손님이 주문한 요리를 정확히 만들어서 대접하면 머니와 함께 '하트'를 추가로 받습니다. 하트는 꾸미기 샵에서 사용됩니다.

## 6. 기술 스택
- **프론트엔드:** React + TypeScript + Vite
- **스타일링:** CSS Modules (모바일 환경 100dvh 및 뷰포트 최적화 적용)
