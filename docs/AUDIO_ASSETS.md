# 냥냥식당 음악 자산

| 파일 | 길이 | 제작·권리 | 사용 |
| --- | ---: | --- | --- |
| `public/game/music-restaurant.mp3` | 87.3초 | 이 저장소의 `scripts/generate_music.py`로 직접 작곡·합성. 외부 곡·녹음·샘플 없음 | 식당 |
| `public/game/music-mart.mp3` | 76.1초 | 같은 생성기에서 만든 마트 변주. 외부 곡·녹음·샘플 없음 | 마트 |
| `public/game/music-kitchen.mp3` | 81.7초 | 같은 생성기의 주방 선율. 외부 곡·녹음·샘플 없음 | 요리 |
| `public/game/music-minigame.mp3` | 71.1초 | 같은 생성기의 놀이 선율. 외부 곡·녹음·샘플 없음 | 놀이 |
| `public/game/music-wardrobe.mp3` | 97.2초 | 같은 생성기의 꾸미기 선율. 외부 곡·녹음·샘플 없음 | 꾸미기 |

2026-09-27에 생성했다. 생성 코드는 NumPy로 음표·화음·베이스·가벼운 리듬을 합성하고 ffmpeg로 MP3를 인코딩한다. 다섯 곡 모두 일정한 32마디 뒤 반복되며 시작·끝에 짧은 페이드를 둔다. 게임은 파일을 Web Audio로 디코딩해 반복하고, 로딩에 실패해도 간단한 합성 음악으로 계속 동작한다. 장면 전환은 약 1초에 걸쳐 음량을 바꾼다. `ffprobe`로 길이와 파일 형식을 확인했고, 브라우저 테스트로 파일 로딩·장면 전환·동일 테마 유지·음량·음소거를 확인했다.

실제 휴대전화 스피커와 헤드폰에서 5~10분간 듣는 음악 품질 검수는 별도로 필요하다. 특히 MP3 반복 경계의 잔향·도입부, 조리 효과음과의 균형, 어린이의 피로감을 듣고 조정한다.
