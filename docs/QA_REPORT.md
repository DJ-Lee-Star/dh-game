# 냥냥식당 v1.0 검증 기록

검증일: 2026-09-26. 로컬 Vite 서버와 Codex 인앱 브라우저에서 실제 UI를 조작했다. 자동 테스트는 Vitest, 정적 검사는 Oxlint, 배포 빌드는 TypeScript + Vite를 사용했다.

## 자동 검증

| 명령 | 결과 |
| --- | --- |
| `npm test` | 15/15 통과 |
| `npm run lint` | 통과, 경고 없음 |
| `npm run build` | 통과 |
| `npm run preview -- --host 127.0.0.1 --port 4173 --strictPort` | 빌드 첫 화면과 주방 도구 이미지 로드 확인, 깨진 `<img>` 0개. 배포 빌드에서도 Lv.1→5 반복 플레이와 첫 시즌 완료 모달 확인 |

자동 테스트는 Lv.1~5 전체 주문 반복 흐름과 재료 구매 가능성, XP 표시·레벨 경계, 잠긴 레시피/재료 부족, 잘못된 서빙, 비밀 요리, 실제 퀘스트와 중복 수령 방지, 중복 없는 선물, 저장 복원과 손상 데이터 처리를 포함한다. 스페셜 손님의 네 번 성공 후 등장, 오주문 뒤 대기, 코인·XP 2배와 하트 추가, 저장 복원 및 이전 저장 형식 마이그레이션도 검증했다. 설정 초기화 후 새 게임 상태와 저장 복원도 자동 테스트했다.

## 브라우저 실사용

| 시나리오 | 확인한 결과 |
| --- | --- |
| 첫 실행 | 소개 화면 → 식당 입장, 첫 주문과 재료·코인·XP 표시 정상 |
| 정상 서빙 | 첫 달걀 프라이 서빙 후 XP `0/300 → 120/300`, 코인 `350 → 530`, 하트 `0 → 1` |
| 재료 순서 오류 | 달걀을 기름보다 먼저 누르면 다음 재료 안내, 조리 진행도와 재고 변화 없음 |
| 조리 취소·재시도 | 재료를 선반에서 넣은 뒤 `처음부터`를 누르면 단계가 초기화되고 달걀 보유 3개 유지 |
| 재료 부족·마트 | 식빵 0개에서 조리 불가 안내와 마트 이동 표시; 식빵 55코인 구매 후 재고 1개·코인 차감 확인 |
| 단계별 조리 | 불 조절 탭, 토스트 뒤집기 포인터 드래그로 진행도 100%, 팬케이크 반죽 → 굽기 두 단계 완료 |
| 오주문 서빙 | 토스트 주문에 달걀 프라이를 서빙하면 원래 주문 유지, 가족 보상 80코인과 XP 45 지급 |
| 레벨 해금 | 실제 반복 플레이로 Lv.1→5 진행. 토스트·우유·팬케이크·버터 토스트의 해금 및 서빙 확인 |
| 첫 시즌 완료 | Lv.5 버터 토스트 정상 서빙 후 완료 모달과 `LV 5 ★` 표시 확인. 닫은 뒤 자유 플레이·새로고침 복원 확인 |
| 일일 퀘스트 | 2회 조리·2회 정상 서빙 후 코인 150·하트 2 수령, 버튼이 `오늘 받았어요`로 비활성화 |
| 선물·꾸미기 | 하트 5개 차감, 클로버 획득·장착, 셰프 모자 위에 실제 표시, 새로고침 후 유지 |
| 비밀 요리 | 달걀 프라이에 소금 추가 → 짭짤 프라이 발견·서빙·도감 등록 확인 |
| 스페셜 손님 등장 | 별도 미리보기 브라우저에서 일반 주문 4번 서빙 후 별님 판다, 최고 해금 레시피인 바삭 토스트 주문, 전용 배경·보상 안내 확인 |
| 스페셜 오주문·복원 | 별님에게 달걀 프라이를 서빙한 뒤에도 바삭 토스트 주문이 유지됨. 새로고침 후 별님, 주문, XP·코인·하트가 그대로 복원됨 |
| 스페셜 정상 서빙 | 바삭 토스트 서빙으로 코인 `1,165 → 1,645`(+480), XP `555 → 855`(+300), 하트 `6 → 9`(+3), Lv.3 해금 확인. 다음 손님은 일반 손님으로 복귀 |
| 저장 복원 | 첫 서빙 후 새로고침해 XP 120, 코인 530, 하트 1과 주문 유지 확인. 시즌 완료 후에도 배지 유지 |
| 모바일 레이아웃 | 320×568, 390×844, 430×932에서 화면 확인. 문서 가로 폭이 뷰포트와 같고 주요 조작 가능 |
| 설정 초기화 진입 | 기존 Lv.3 기록이 보이는 별도 미리보기에서 설정 화면과 초기화 확인 단계 표시, `취소` 후 Lv.3·코인 1,645·하트 9 유지 확인. 실제 초기화는 자동 테스트의 별도 저장소에서 검증 |

화면에서 캐릭터의 기본/기쁨 표정 전환, 점프·흔들림, 냄비·팬·보울 그림, 재료 투입, 마트 및 완료 모달을 확인했다. 스페셜 손님의 별도 그림과 강조 카드도 확인했다. 생성 에셋 18개는 WebP로 약 2.59MiB이며 투명 배경을 유지한다.

## 남은 검증 범위

실제 iOS/Android 기기와 Safari에서 터치 감각·성능·음량을 측정하지 않았다. 브라우저 저장은 기기 간 동기화되지 않는다. 현재 동작은 첫 시즌 로컬 플레이를 기준으로 검증했으며, 배포 서비스의 계정·원격 저장·운영 지표는 범위에 포함되지 않는다.
