# 냥냥식당 v1.0 아트 에셋 기록

캐릭터·표정·배경·조리 도구는 Codex 이미지 생성 도구로 새로 만들었다. 공개 게임에는 `public/game/`의 WebP만 포함한다. 생성 원본 PNG는 작업 환경의 `C:\Users\10116\.codex\generated_images\01a0dc51-5aca-72a2-bcfa-8e99b90c08bc`에 남아 있다.

## 아트 방향과 생성 지시 요약

- 공통: 7~11세 대상의 따뜻한 그림책풍 모바일 요리 게임, 크림·코코아·살구·세이지 팔레트, 선명한 윤곽선, 부드러운 채색, 텍스트와 로고 제외.
- `chef-cat.webp`: 주황 줄무늬 고양이 셰프, 흰 조리모·앞치마와 민트 스카프, 손에 나무 숟가락을 든 전신 컷아웃.
- `customer-dog.webp`, `customer-rabbit.webp`, `customer-fox.webp`, `customer-bear.webp`: 파란 멜빵 강아지, 보라 원피스 토끼, 녹색 조끼 여우, 녹색 앞치마와 장바구니 곰. 모두 같은 그림체의 투명 전신 컷아웃.
- `customer-panda.webp`, `customer-panda-happy.webp`: 별 브로치가 달린 남색 코트와 크림색 목도리를 두른 스페셜 손님 별님. 기본 대기 자세와 기뻐하는 자세를 같은 그림체의 투명 컷아웃으로 생성.
- 각 `*-happy.webp`: 해당 원본 캐릭터를 참조해 눈을 감고 크게 웃으며 팔·앞발을 올린 기쁨 표정과 자세를 생성. 옷과 종·색상 정체성 유지.
- `bg-restaurant.webp`, `bg-kitchen.webp`, `bg-mart.webp`: 따뜻한 목재 바닥과 소품이 있는 식당·주방·마트 실내. 캐릭터와 UI를 올릴 수 있도록 인물과 글자는 제외.
- `tool-pan.webp`: 3/4 탑다운 프라이팬, 넓은 검은 내부, 구리색 테두리와 나무 손잡이.
- `tool-pot.webp`: 3/4 탑다운 작은 민트 법랑 냄비, 빈 크림색 내부와 양쪽 손잡이.
- `tool-bowl.webp`: 3/4 탑다운 민트 세라믹 반죽 보울, 빈 크림색 내부.

캐릭터와 도구 컷아웃은 투명 배경으로 생성했다. 총 18개 에셋을 WebP로 변환해 약 2.59MiB로 줄였으며, 투명도를 확인했다. 음식·재료·장착 장식은 `src/components/GameArt.tsx`의 벡터 그림으로 같은 팔레트에 맞췄다. 캐릭터의 대기·점프·생각, 도구의 흔들림·증기·반죽 소용돌이, 재료 투입과 UI 전환은 CSS 애니메이션과 상태 전환으로 구현했다. OS의 움직임 줄이기 설정이 켜져 있으면 애니메이션을 줄인다.
