# 첫 1분 플레이 재설계와 검수

2026-09-27. 8세 어린이가 첫 플레이에서 방법을 알 수 없고 재미없다고 중단했다는 피드백을 반영했다. 이전 [휴대폰 화면 수정](PHONE_FIRST_PLAY_QA.md)은 화면 잘림과 조작 가능 여부를 검증했지만, 첫 행동의 발견 가능성과 첫 보상까지의 길이는 해결하지 못했다.

## 바뀐 첫 주문

1. 새 프로필에서는 몽실이의 부탁과 `노릇 달걀 프라이 만들기` 버튼을 첫 화면 안에 함께 보여 준다. 도감·퀘스트·진행 카드는 첫 서빙 전까지 접어 첫 목표에 집중한다.
2. 이 버튼으로 들어온 첫 프라이는 재료 보관소를 찾지 않고 시작한다. 달걀과 손잡이에 눈에 띄는 테두리와 `여기 눌러!` 표시가 붙는다. 누를 때마다 음식이 변하고 짧은 반응이 나온 뒤 다음 장면으로 자동 이동한다. 시간 제한이나 실패 벌점은 없다.
3. 완성 접시에서는 분홍·크림·민트 중 색을 골라 결과를 바로 본다. 서빙 뒤 몽실이가 먹고 웃으며 첫 손님 스티커가 나타난다. 스티커는 접시 앨범에도 보인다.
4. 기존 직접 재료 찾기, 드래그 조리, 전체 플레이팅은 `요리` 메뉴에서 다른 요리를 선택하거나 첫 주문 뒤에도 이용할 수 있다. 서버의 재료 차감과 보상 규칙은 그대로 적용된다.

## 검수 결과

- 280×568, 320×568, 390×844, 430×932에서 첫 시작 버튼과 주문 카드가 내비게이션 위에 있고 서로 겹치지 않는지 확인했다.
- 280px에서 새 프로필 → 달걀 누르기 → 손잡이 누르기 → 접시 색 고르기 → 완성 → 서빙 → 앨범 스티커를 검증했다. 320px 모바일 터치 입력도 통과했다.
- 일반 조리의 첫 프라이와 가족 부탁, 전체 레시피, 마트 등 기존 기능을 브라우저 회귀 테스트로 확인했다. 테스트 결과와 실행 명령은 커밋 및 Actions 기록을 따른다.
