# 냥냥식당 v2 콘텐츠·경제 기준

수치의 원본은 `src/v2/content.ts`와 `src/v2/engine.ts`다. 조리 완료 시 XP와 재료 차감이 한 번 일어나며, 서빙 시 코인·하트가 지급된다. 조리 취소와 단계 재시작은 서버 상태를 바꾸지 않는다.

## 성장과 레시피

| 레벨 | 누적 XP | 새 일반 레시피 | 시크릿 |
| --- | ---: | --- | --- |
| 1 | 0 | 노릇 달걀 프라이, 딸기잼 토스트, 포근 코코아 우유 | — |
| 2 | 120 | 바나나 토스트, 토마토 달걀 컵 | 비밀 소금꽃 프라이 |
| 3 | 420 | 쭉쭉 치즈 토스트, 과일 요거트 컵 | — |
| 4 | 780 | 구름 팬케이크, 딸기 스무디 | 비밀 별딸기 팬케이크 |
| 5 | 1300 | 따끈 라면, 꽃밭 샌드위치, 버터 토스트 | — |

Lv.1 음식은 각각 120 XP다. 한 접시를 만들면 Lv.2, 이어 Lv.2 음식 두 접시(각 150 XP)를 만들면 총 420 XP로 Lv.3이 된다. 레시피 14종은 각기 2~3개의 의미 있는 조리 단계를 가진다. 시크릿은 해당 레벨에서 힌트를 보고 만들어 발견하며, 기본 주문을 대체할 수 있다. 최고 레벨 뒤에도 주문과 요리·꾸미기는 계속된다.

## 재료와 보관 장소

| 장소 | 재료와 마트 가격(코인) |
| --- | --- |
| 냉장고 | 달걀 40, 우유 65, 토마토 45, 치즈 55, 요거트 60, 버터 45, 딸기 65, 상추 45 |
| 간식 선반 | 식빵 55, 딸기잼 45, 바나나 50 |
| 상온 보관장 | 코코아 가루 35, 밀가루 50, 라면 70, 라면 스프 20, 식용유·소금·설탕 무료 |

처음에는 350코인과 달걀 3개를 준다. 무료 양념은 재고 소모와 미니게임 가치 계산에서 제외한다. 마트는 품목당 최대 20개, 한 번에 30개까지 구매한다.

## 보상과 반복 플레이

| 행동 | 기준 |
| --- | --- |
| 일반 손님 | 요리별 155~420코인, 하트 1개. 연속 성공 3회째부터 코인 15% 추가. |
| 스페셜 별님 | 일반 손님 네 번 성공 뒤 방문. 해당 요리 코인 2배, 하트 3개. |
| 가족 | 음식 재료값 + 기본 45코인. 선호 음식은 재료값 + 110코인과 하트 1개. 원래 주문은 유지. |
| 이야기 | 손님 정상 서빙 3·6·9회에 새 장면·스티커와 100코인 각 1회. |
| 오늘의 목표 | 요리 2회: 150코인. 정상 서빙 2회: 하트 2개. 매일 별도 기록, 중복 수령 방지. |
| 하트 선물 | 하트 5개로 아직 소유하지 않은 모자·액세서리 하나 획득. 모두 소유하면 다시 뽑을 수 없음. |

재료 받기 놀이는 참가비 100코인을 시작할 때 차감한다. 한 판은 약 12.4초이며 식재료 12개가 떨어진다.

| 점수 | 지급 재료 | 마트 가격 합계 |
| --- | --- | ---: |
| 0~3 | 달걀 2, 식빵 1 | 135코인 |
| 4~7 | 우유 2, 식빵 1 | 185코인 |
| 8~12 | 달걀 2, 우유 2, 딸기잼 1 | 255코인 |

중도 포기하면 참가비는 돌아오지 않고 보상도 없다. 새로고침하면 진행 중인 판을 이어 간다. 완료·포기 후 같은 판 결과를 다시 제출할 수 없다.

## 코인 꾸미기

| 슬롯 | 아이템과 가격(코인) |
| --- | --- |
| 모자 | 딸기 베레모 180, 별빛 모자 260, 꽃 모자 220 |
| 의상 | 민트 앞치마 200, 딸기 앞치마 280, 하늘 앞치마 320 |
| 액세서리 | 리본 목걸이 160, 방울 목걸이 230, 클로버 배지 250 |
| 식당 배경 | 노을 식당 350, 꽃밭 식당 400 |

구매한 물건은 소유 목록에 남고 슬롯별로 자유롭게 장착·해제할 수 있다. 하트 선물과 코인 상점은 같은 소유 목록을 사용해 중복 물건에 값을 지불하지 않도록 한다.
