# 어린이 플레이 경험 개선 구현·검수

기준: [플레이 경험 검토](V2_CHILD_PLAY_EXPERIENCE_REVIEW.md), 2026-09-27.

## 구현

| 범위 | 결과 |
| --- | --- |
| 진행 불능·입력 | 코인과 재료가 모두 소진된 상태에서 달걀 1개 회복. 작은 이동을 누적해 조리 판정. 도구 드래그의 터치 대안인 `톡톡 조리` 추가. |
| 한 화면 주방 | 레시피 4개씩, 보관소 재료 6개씩 페이지 전환. 320×568, 390×844, 430×932, 태블릿 세로·가로에서 선택·조리·장식의 본문과 재료 트레이 스크롤 제거. |
| 이어 하기 | 조리 단계·진행량·재료 선택·접시·장바구니를 셰프 프로필별 브라우저 임시 기록에 보존. 마트 왕복과 새로고침 뒤 이어서 진행. 완료 뒤 해당 임시 기록 정리. |
| 조리·접시 | 달걀·잼 토스트·코코아 등에서 진행에 맞춘 음식 변화. 동작별 손 시범. 장식 최대 3개와 위치 이동·삭제·되돌리기, 접시 색 3개와 이름. 완성 접시가 서빙·앨범에 같은 모습으로 남음. 토마토·딸기의 씻기→썰기에는 같은 재료 한 개를 이어 사용. 딸기 바나나 꼬치와 전용 음식 그림 추가. |
| 대접·이야기 | 접시가 식사 장면에서 남고 결과를 `계속하기`로 닫음. 가족 대접도 이야기 진행, 방문 횟수와 좋아하는 음식 추억 기록. 가족마다 음식과 모양이 정해진 부탁을 하나씩 주고 첫 완수에 보상 지급. 이야기 완료 시 식당 소품 표시. Lv.5 선택 목표 3개. |
| 장보기·놀이 | 현재 요리의 부족 재료 메모, 상품 전체 터치, 무료 연습, 점수별 고정 재료 꾸러미와 중단 비용 안내. 장식 재료 비용도 가족 보상에서 보전. 시간 제한 없이 재료를 보관 장소로 분류하는 무료 놀이 추가. |
| 음악 | 직접 제작한 식당·마트·주방·놀이·꾸미기 음악 5개를 파일로 제공. 같은 테마는 재시작하지 않고 장면 전환 시 페이드. 숨은 탭에서 재생 정지, 파일 로딩 실패 시 합성 음악으로 대체. 권리·생성 방법은 [음악 자산 표](AUDIO_ASSETS.md). |

## 자동 검수

- `npm test`: 37개 통과. 기존 저장 복원, 경제 회복, 앨범·장식 좌표, 가족 의뢰, 목표 중복 보상 검증.
- `npm run lint`: 경고 없이 통과.
- `npm run build`: TypeScript와 Vite 빌드 통과.
- `npm run test:e2e`: 13개 통과. 새 프로필부터 Lv.1~5 전 요리, 조리 동작, 손님·가족 서빙, 구매 재시도, 소형 화면·터치·임시 기록, 앨범 다시 만들기, 무료 연습, 두 번째 놀이, 음악 파일 재생을 브라우저에서 검증.
- E2E는 `data/e2e.sqlite` 전용 DB를 사용한다. 기존 플레이 기록은 초기화하지 않았다.

## 추가로 필요한 실제 사용 검수

브라우저 자동화는 실제 7~11세 어린이의 이해·재미를 판단하지 못한다. [검토 문서의 관찰 계획](V2_CHILD_PLAY_EXPERIENCE_REVIEW.md#12-실제-어린이와-확인할-계획)에 따라 보호자 동의를 받은 어린이와 Android·iPhone 실기기에서 첫 주문, 재료 찾기, 접시 꾸미기, 5~10분 음악 청취를 확인해야 한다. 생성 음악은 기술적으로 로딩·반복되지만 청취 품질과 반복 피로를 사람 귀로 승인한 상태는 아니다.
