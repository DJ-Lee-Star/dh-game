# 냥냥식당 v1.0 구현 범위

이 문서는 과거 Phase 2 초안을 대체한다. 현재 코드는 Lv.1~5를 첫 완결 범위로 삼는다.

## 완료

- 주문 → 마트 → 순서별 재료 투입 → 탭/드래그 조리 → 서빙 반복 흐름
- 다섯 레벨, 기본 레시피 다섯 개, 비밀 레시피 한 개, 일반 손님 네 명과 반복 방문하는 스페셜 손님 한 명
- 정확한 경험치 표시, 레벨 해금, 재료 구매/소모, 실패 후 재시도
- 실제 일일 퀘스트, 중복 수령 방지, 중복 없는 꾸미기 획득/장착
- 자동 저장·새로고침 복원, 설정에서 현재 브라우저 플레이 기록 초기화, 첫 시즌 완료 화면
- 통일된 생성 캐릭터·표정·배경·도구 이미지, 동작 애니메이션, 모바일 UI
- 자동 테스트, 빌드, 린트와 모바일 브라우저 시나리오 검증
