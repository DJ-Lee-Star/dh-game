# 냥냥식당 상용화 대규모 업데이트 TODO (Phase 2)

이 문서는 냥냥식당을 '단순한 프로토타입'에서 **'실제 스토어에 출시할 수 있는 상용 모바일 게임'** 퀄리티로 끌어올리기 위한 구체적인 개발 마일스톤입니다.

---

## 1. 🍳 인터랙티브 조리 미니게임 (조작감 극대화)
단순한 버튼 클릭(`onClick`)을 넘어, 실제 요리하는 듯한 손맛을 주는 터치/드래그 기반 미니게임으로 개편합니다.
- [ ] **불 켜기 애니메이션**: 버튼을 누르는 것이 아니라, 가스레인지 다이얼 이미지를 터치하고 반원 궤적으로 드래그해야 불이 켜지도록 물리적 조작감 구현 (`onTouchMove`).
- [ ] **반죽 섞기 (보울)**: 화면의 보울 위에서 손가락(마우스)을 빠르게 빙글빙글 문지르면 게이지가 차오르고 반죽이 완성되는 인터랙션 추가.
- [ ] **도마 액션 (재료 썰기)**: 특정 재료(예: 파, 소시지)는 도마 위로 올려 화면을 위아래로 스와이프(Swipe)하여 썰어내는 미니게임 적용.
- [ ] **시각 효과(VFX)**: 고기가 구워질 때 기름이 튀는 파티클 효과, 물이 끓어오르는 기포 애니메이션(CSS/Canvas) 추가.

## 2. 🐶 캐릭터 에셋 풀 체인지 및 모션/표정 적용
이모티콘과 정적인 이미지를 버리고, 살아 숨쉬는 캐릭터 시스템을 구축합니다.
- [ ] **개별 캐릭터 에셋 생성**: 강아지, 토끼, 여우, 판다, 수달, 햄스터 등 6종 이상의 캐릭터 고해상도 2D 이미지 생성.
- [ ] **캐릭터 상태별 3가지 표정 에셋 분리**:
  - `Normal (대기)`: 자리에 앉아 메뉴판을 보며 눈을 깜빡이는 기본 모션.
  - `Waiting (지루함/기대)`: 대기 시간이 길어지면 시계를 보거나 땀을 흘리는 묘사.
  - `Happy (성공)`: 정확한 요리를 받았을 때 방방 뛰며 팁을 던지는 기쁜 모션.
  - `Disappointed (실패)`: 까맣게 탄 요리를 받으면 우울하게 돌아가는 표정.
- [ ] **입장/퇴장 애니메이션**: 화면 밖에서 뽈뽈뽈 걸어 들어오고 나가는 CSS Keyframes 걷기 모션 추가.

## 3. 📈 레벨 스케일링 기획 및 경제 시스템 (Lv.1 ~ Lv.20)
미리 기획된 로그(Log) 스케일링 경험치 곡선에 맞춰 게임의 뼈대를 확장합니다.
- [ ] **성장 시스템 하드코딩**: 레벨 1부터 20까지 필요한 누적 XP 테이블 및 30여 종의 레시피 락(Lock) 해제 로직 구현.
- [ ] **UI 진척도 시각화**: 레벨이 높을수록 마트의 선반이 꽉 차고, 텅 비어있던 '도감 북'이 실루엣(물음표) 아이콘들로 가득 차 수집욕을 자극하도록 UI 고도화.
- [ ] **보상 밸런싱**: 고급 레시피일수록 (조리 과정이 길어짐) 판매 단가와 획득 경험치가 기하급수적으로 높아지도록 설계.

## 4. 🚀 상용 게임 4대 핵심 기능 추가
유저의 리텐션(재접속률)과 몰입도를 높이는 상용 게임의 필수 시스템입니다.
- [ ] **일일 퀘스트 및 업적 (Quests & Achievements)**
  - 일일 미션 보드 추가 (예: "오늘 토끼 손님 3명 만족시키기", "퍼펙트 반죽 5회"). 달성 시 특수 재화 '루비' 지급.
- [ ] **주방 기구 업그레이드 (Upgrades)**
  - 골드를 소모하여 능력을 키우는 상점 추가.
  - 예: '테프론 코팅 프라이팬' (고기가 타는 시간 연장), '초고속 믹서기' (반죽 스와이프 요구 횟수 감소).
- [ ] **하트 가챠 상점 (Decor Gacha)**
  - 요리 성공 시 받는 '하트'를 소모하여 알을 뽑는 캡슐 뽑기 UI.
  - 냥냥 셰프의 모자(요리사 모자, 고양이 귀마개 등)와 식당 테마 변경권 획득 로직.
- [ ] **사운드 시스템 (SFX & BGM)**
  - HTML5 Audio를 활용한 게임의 생동감 부여.
  - 배경음악(따뜻하고 발랄한 마림바 사운드), 지글지글 튀기는 소리, 써는 소리, 완료 시 팡파레 등.

## 5. 🧪 테스트 및 QA (Quality Assurance) 프로세스
상용 게임 수준의 안정성을 확보하기 위해, 기능 구현과 병행하여 체계적인 테스트를 진행합니다.
- [ ] **구현 중간중간 단위 테스트 (Intermediate Testing)**
  - 새로운 미니게임(반죽, 썰기)이 추가될 때마다 모바일 터치 이벤트(`onTouchMove`, `onSwipe`)가 PC 마우스 클릭과 동일하게 씹히지 않고 잘 작동하는지 브라우저에서 즉시 테스트.
  - 레벨업 시 마트 재료가 즉각적으로 해금되는지 상태(State) 갱신 테스트.
- [ ] **구현 완료 후 시나리오 기반 통합 테스트 (Scenario Testing)**
  - **시나리오 A (초보자 플로우)**: 게임 첫 진입 -> 튜토리얼 툴팁 확인 -> 계란 프라이 성공 -> 레벨 2 달성까지의 흐름이 매끄러운지 검증.
  - **시나리오 B (하드코어 플로우)**: 피버 타임(Fever Time) 중 복잡한 요리(예: 딸기 탕후루)를 주문받았을 때, 제한 시간 내에 조리 액션(썰기->굽기)이 끊김 없이 연속으로 성공 가능한지 검증.
  - **시나리오 C (실패 및 엣지 케이스)**: 요리를 불에 올려두고 다른 탭(마트 등)에 갔다가 돌아왔을 때 음식이 타버리는 처리나 시간 초과 로직이 정상 작동하는지 확인.
- [ ] **사용성 보완 및 폴리싱 (Polishing)**
  - 테스트 중 발견된 불편한 점(예: 버튼 터치 영역이 너무 작음, 애니메이션이 느려 답답함)을 찾아내어 픽셀 단위로 수정 및 보완.
  - 메모리 누수 방지 (사운드 객체나 파티클이 제때 가비지 컬렉터에 수집되는지 확인).
