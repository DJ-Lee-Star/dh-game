# 냥냥식당 v2 후속 개편 자산 조사

작성: 2026-09-27 · 기준: `main`의 후속 개편 작업

## 보존과 제작 기준

- 작업 전 Git 작업 폴더는 깨끗했고 `main`은 `074533b`였다. 이 PC에는 실제 플레이 DB `data/nyanyang.sqlite`가 없었다. 브라우저의 기존 프로필 기록을 지우지 않았다. 검증용 `data/e2e.sqlite`만 별도 사용한다.
- 320×568, 390×844, 430×932에서 크기와 가림을 확인한다. 크림·살구·민트·코코아 톤, 부드러운 갈색 윤곽, 왼쪽 위의 따뜻한 빛, 접지 그림자를 공통 기준으로 쓴다.
- 목록 그림과 실제 장착·서빙 결과가 같은 자산을 참조하게 한다. 잠금·재고 0개·부족 코인은 색 외에 글자로 표시한다. 조작 대상의 그림과 포인터 판정을 같은 화면 요소로 연결한다.
